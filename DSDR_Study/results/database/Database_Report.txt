Load flow: AC unbalanced, 3-phase (ABC).  Short circuit: complete method (pre-fault load flow), initial symmetrical current Ikss.

Reference direction of the reclosers (+ = forward = away from the grid):
  Device | Relay units in the model                         | Relay terminal | Measured element | Forward =   | Line distance from the grid        
  -------+--------------------------------------------------+----------------+------------------+-------------+------------------------------------
  R1     | R1 Fast, R1 Delayed                              | RG60           | LOHL650-632      | RG60 -> 632 | 0 (relay end) / 2000 (other end)   
  R2     | R2 Fast, R2 Delayed, R2 Rev Fast, R2 Rev Delayed | 671            | LOHL632-671end   | nDL5 -> 671 | 4000 (relay end) / 3667 (other end)
R2 sits at the 671 end of line 632-671. PowerFactory counts current positive from the terminal into the element, i.e. 671 -> 632 for R2, so R2's PowerFactory values are multiplied by -1 to get the forward reference 632 -> 671. R1's values are used as they are.

DG and transformer data as found in the model:
  DG: synchronous, 4.05 MVA / 0.69 kV at node 692 through a 4.16/0.69 kV transformer, uk = 15 % (Dyn5)
  Table I: xd 1.400, xq 1.372, xd' 0.231, xq' 0.800, xd'' 0.118, xq'' 0.118, xl 0.050, rstr 0.0014 pu
Modelling choices - values not fixed by the method, with what the model uses:
  1. Source impedance. Model: External Grid 115 kV, Sk'' = 100000 MVA, behind the 5 MVA 115/4.16 kV substation transformer, uk = 8.06 % (IEEE 13-node benchmark data).
  2. DG operating point for the load flow. Model: P = 3.24 MW, voltage control (constv) at 1.00 pu; Q follows from the load flow.
  3. Relay / CT reference direction: defined above from the use of R2 (forward for faults at 671 and beyond).
  4. Short-circuit method: complete method (pre-fault load flow).
  5. 'Farthest node' of each protection section: taken from the model's line lengths.
  6. Fault location in the upstream section 632-671: the distributed-load lateral 'DL' at the middle of the line.
  7. Regulator taps (fixed, from the model): VregA +10, VregB +8, VregC +11.
